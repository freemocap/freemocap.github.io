# Specialization tracks

Tutorials teach you to use FreeMoCap. Specialization tracks go further.
They cover the different domains FreeMoCap's output feeds into, once
recording and processing feel familiar.

There are three tracks, matching three different reasons someone
reaches for motion capture data in the first place.

## Technology

This track covers how FreeMoCap's own software works.
[SkellyCam](https://github.com/freemocap/university/blob/main/skellyuniversity/modules/3000-specialization/3100-technology/3110-skellycam/3110-skellycam-overview.md)
handles camera sync, [SkellyTracker](https://github.com/freemocap/university/blob/main/skellyuniversity/modules/3000-specialization/3100-technology/3120-skellytracker/3120-skellytracker-overview.md)
handles pose estimation, [SkellyForge](https://github.com/freemocap/university/blob/main/skellyuniversity/modules/3000-specialization/3100-technology/3130-skellyforge/3130-skellyforge-overview.md)
handles post-processing, [SkellyBlender](https://github.com/freemocap/university/blob/main/skellyuniversity/modules/3000-specialization/3100-technology/3140-skellyblender/3140-skellyblender-overview.md)
handles the Blender integration, and the [core app](https://github.com/freemocap/university/blob/main/skellyuniversity/modules/3000-specialization/3100-technology/3150-freemocap-core/3150-core-overview.md)
runs them all together. This track is for people who want to build on
FreeMoCap itself, not just use it. Start at the
[track overview](https://github.com/freemocap/university/blob/main/skellyuniversity/modules/3000-specialization/3100-technology/3100-tech-overview.md).

## Science

This track covers research applications. Measurement principles, data
analysis workflows, biomechanics, and the neuroscience of movement all
fall under it. This track is for researchers and clinicians who need to
know what the data actually supports, not just how to produce it. Start
at the
[track overview](https://github.com/freemocap/university/blob/main/skellyuniversity/modules/3000-specialization/3200-science/3200-science-overview.md).

## Art

This track covers creative applications. Cleaning up motion capture
data for character animation, and getting it into game engines for
interactive work, both fall under it. This track is for animators and
game developers. Start at the
[track overview](https://github.com/freemocap/university/blob/main/skellyuniversity/modules/3000-specialization/3300-art/3300-art-overview.md).
